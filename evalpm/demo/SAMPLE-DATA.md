# Sample data

Everything in this folder is invented: eight made-up tasks for a made-up "Release Notes Writer", canned replies, canned judge answers (`verdicts.json`) and 20 canned human marks (`marks.json`). No model was called. The demo exists to show what a report looks like and which questions it answers, not to show that any agent works.

The canned verdicts include a task where plain wins (`rn-03`) and a tie (`rn-06`) on purpose.
