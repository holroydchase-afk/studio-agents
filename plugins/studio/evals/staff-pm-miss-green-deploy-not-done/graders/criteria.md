Recall of ES-S5, a spec miss we already know was real (pattern: done-without-done-check). The answer must be a spec or plan with testable acceptance criteria, and it passes only if it explicitly includes: a no-go (or go with the named condition) because the plan's own done check, loading the link on a phone, has no evidence yet, listing it as not met rather than rounding up from the green deploy, and who does the check. Generic criteria, or a mention in passing with nothing testable, do not count. Rank at P1 or higher where it ranks anything. Other content doesn't change the result.
