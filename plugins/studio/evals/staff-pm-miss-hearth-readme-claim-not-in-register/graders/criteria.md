The answer (a spec, plan or go/no-go verdict) must give testable criteria or evidence-based verdicts, and it passes only if it explicitly includes: BOTH: (1) Every security or privacy sentence in the new README maps to a row in the claims register, and any claim whose row is missing or gated is softened or the row is added first; AND (2) The done check greps the README's claims against the register and lists any that are unmatched. Generic criteria, or a mention in passing with nothing testable, do not count. Rank at P1 or higher where it ranks anything. Other content doesn't change the result.
