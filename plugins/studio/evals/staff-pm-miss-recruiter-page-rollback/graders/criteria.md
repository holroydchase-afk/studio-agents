Recall of RR-S7, a spec miss we already know was real (pattern: missing-criteria). The answer (a spec, plan or go/no-go verdict) must give testable criteria or evidence-based verdicts, and it passes only if it explicitly includes: a rollback path if the login change fails on the live page, and a check that only the owner can see the list (including a signed-out and a different-user case), each with an acceptance criterion. Generic criteria, or a mention in passing with nothing testable, do not count. Rank at P1 or higher where it ranks anything. Other content doesn't change the result.
