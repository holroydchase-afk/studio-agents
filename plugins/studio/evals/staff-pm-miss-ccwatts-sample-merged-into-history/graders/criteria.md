Recall of CC-S20, a spec miss we already know was real (pattern: missing-criteria). The answer (a spec, plan or go/no-go verdict) must give testable criteria or evidence-based verdicts, and it passes only if it explicitly includes: BOTH: (1) The plan says which runs write history and states that a run on a sample or an explicit path never writes or reads the user's real history; AND (2) A test runs the documented sample command in a throwaway home and asserts the history file is unchanged. Generic criteria, or a mention in passing with nothing testable, do not count. Rank at P1 or higher where it ranks anything. Other content doesn't change the result.
