Recall of HE-S21, a spec miss we already know was real (pattern: missing-criteria). The answer (a spec, plan or go/no-go verdict) must give testable criteria or evidence-based verdicts, and it passes only if it explicitly includes: BOTH: (1) The spec lists every path a relative can read a group name (screen, RPC, table read, data export) and says each is closed; AND (2) A test signs in as a relative and calls the raw table read and the export, asserting no group name comes back. Generic criteria, or a mention in passing with nothing testable, do not count. Rank at P0 or higher where it ranks anything. Other content doesn't change the result.
